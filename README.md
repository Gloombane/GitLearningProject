📌 О проекте

Student Library Booking System — это веб-приложение для автоматизации работы университетской библиотеки. 
Система позволяет студентам искать нужную учебную литературу и бронировать её онлайн, а библиотекарям — управлять каталогом, выдачей книг и отслеживать задолженности.

🌟 Основной функционал
- Для студентов: авторизация, поиск книг по автору/названию/тегам, просмотр доступного количества, бронирование книги на определенный срок, история своих бронирований.
- Для администраторов (библиотекарей): добавление/удаление книг из каталога, подтверждение выдачи и возврата, просмотр списка должников.

🛠 Технологический стек

- Backend: Java 17, Spring Boot (Web, Data JPA, Security)
- Frontend: React.js, React Router, Axios
- База данных: PostgreSQL
- Сборка и деплой: Maven (Backend)
